# SK Silk & Saree's – Tamil Nadu Saree Store

A complete frontend portfolio project built with React + Vite + Tailwind CSS.

## Included
- Tamil Nadu inspired saree collections
- Kanchipuram Silk
- Madurai Sungudi
- Chettinad Cotton / Kandaangi
- Bridal collection
- Responsive landing page
- Login form validation + password visibility
- Admin dashboard
- Recharts analytics
- Light / dark mode
- Mobile sidebar
- Search and add-to-cart UI
- Reusable components

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Important image note

The demo catalog references publicly accessible image URLs for the sample presentation. Before using the project commercially, replace those URLs with images you own or have permission to use. The image URLs and collection descriptions were selected as visual references for Tamil Nadu textile styles.
